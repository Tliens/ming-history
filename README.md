# 明朝历史知识网站 · 项目总仓

一个面向 **学生、明史爱好者、小说创作者** 的明代（1368–1644，附南明简编）历史知识网站，
以**交互历史地图为第一入口**（首页即地图）、以「权力结构与演变」为叙事主线，配合动态图表，讲清这个王朝 276 年的运转逻辑。

## 三类受众，三条主线

- **学生**：时间轴 + 知识卡片 + 术语弹窗 + 每页「一句话→段落→深读」三层阅读
- **爱好者**：深度专题、人物关系网络、交互地图、轶闻考据
- **小说创作者**：称谓表、官品速查、科举流程、物价服饰、年号换算器、常见误区清单
