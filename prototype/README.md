# prototype/ · D6 MapCore 高保真原型

## 运行

```bash
cd 仓库根目录
python3 -m http.server 4173
# 浏览器打开 http://127.0.0.1:4173/prototype/map-core.html
```

单文件 `map-core.html`（Leaflet 1.9.4 本地 vendor），加载 `../src/geojson/` 下五个真实数据图层。

## 已知边界

- 底图用 OSM 标准瓦片（无需密钥）；曾用 Carto 出现「API KEY REQUIRED」水印，已弃用
- 年号文本首次渲染的视觉抽查曾报「洪武元年」，经程序复核为视觉模型误读（实际输出正确），保留程序化验证结论
- 政区为 1391 切片（明初），无明中后期变化——与 R10 校勘笔记一致；中后期补图走 CHGIS V6 时间序列（非阻塞）
