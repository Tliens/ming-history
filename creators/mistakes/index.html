误区清单（53 条）

历史剧与网文的常见硬伤逐条辨析。每条给「正确写法」与史料依据。

情节核查（史实边界 + 演绎空间）

不是「不能写」，而是告诉你在哪条边界内怎么写才好看。

🎬 劫法场
史实边界：死刑须三法司定谳、皇帝勾决，秋后于闹市处决，有重兵监刑——组织劫法场几乎等于集体自杀，且成功率趋近于零。演绎空间：买通狱卒与文书改判、恩旨特赦、「顶包」受刑，才是现实可行的营救路径，冲突也更高级。
🎬 夜市
史实边界：明代京城有宵禁与夜巡（锦衣卫巡街），夜聚饮酒可被捕。演绎空间：上元灯市通宵是合法的（灯市口即因此得名）；江南市镇的夜市在明中后期实际松弛——把场景放在江南或灯节，夜戏就成立。
🎬 出远门没有路引
史实边界：军民出百里即需路引（官府签发，写明去向与期限），关津客店查验，无引以逃户/逃军论处。演绎空间：伪造路引、借僧道度牒通行、驿传火牌冒用，都是真实存在的灰色操作——也是天然的情节引擎。
🎬 掏出一张「银票」
史实边界：银票是清代产物。明代大额支付靠现银（需验成色、剪银）与宝钞；明末出现「会票」雏形。演绎空间：护送现银的镖行/标船生意因此真实兴盛——写一场「劫标」比写假银票扎实。
🎬 女扮男装进考场
史实边界：科举有识认官、同考生保结、面部 aging 核对等多重身份核验，女性混入几乎无可能。演绎空间：才女以文才间接参与（代父兄作文、幕后清客、刊刻才名）有真实先例，冲突不逊于考场。
🎬 街头设擂、生死状比武
史实边界：明代无官设擂台制，私斗致伤有刑责，「生死状」不免责。演绎空间：军中校场比试、卫所演武、镖行切磋是合法的「打戏」舞台。
🎬 飞鸽传书送军情
史实边界：军情驿传是国家级系统（六百里加急），军报不依赖信鸽。演绎空间：民间与谍报小范围用信鸽有记载——用在江湖情报可以，用在九边军报就穿帮。
🎬 一碗烧刀子一饮而尽
史实边界：明代主流是低度黄酒/米酒，蒸馏烧酒明中后期才在北方渐兴。演绎空间：按年代与地域写酒——永乐朝的豪饮是黄酒式的豪饮，写出蒸馏酒的烈度就是穿越。
🎬 击鼓升堂随到随审
史实边界：州县有放告日（受理期，多为每月特定日子），状纸有格式与字数限制，不合规即「不准」。演绎空间：讼师与刑名师爷的幕后操作真实存在——写一场「状纸怎么递进去」的戏，比当堂翻案扎实得多。
🎬 当铺随便压价、利滚利无上限
史实边界：当铺（解库）遍地都是，但王法有「违禁取利」上限（月利三分为限、利不过本）。演绎空间：真正的黑幕在「慢收当物、虫蛀霉变不认」的合同陷阱——比单纯的恶霸当铺更真实。

词汇与设定穿帮

✗ 「大人」满天飞 3
✓ 明代官员互称「老先生」「部堂」「台台」，称「大人」指父亲。清宫剧式对话请全部重写。
✗ 宦官自称「奴才」 3
✓ 明代宦官对皇帝自称「奴婢」；「奴才」是清代旗人用语。
✗ 锦衣卫人人飞鱼服、绣春刀 3
✓ 飞鱼服是「赐服」，仅赏给高级官员与锦衣卫堂上官；绣春刀亦为御赐仪仗刀。基层校尉穿的是普通青绿制服。
✗ 圣旨开头「奉天承运皇帝诏曰」 3
✓ 正确的读法是「奉天承运皇帝，诏曰」——「奉天承运皇帝」是朱元璋的尊号修饰；且明代诏书有诏、制、诰、敕之分，用途不同。
✗ 「奉天承运」念成四三句 3
✓ 同上：断句错误是影视剧最大发明。
✗ 县太爷升堂喊「威——武——」 3
✓ 明代州县审案有喝礼但「威武」呼喝是戏剧程式；堂吏喊的是「堂威」需肃静。地摊文学请慎用。
✗ 刽子手口含喷酒再砍头 3
✓ 喷酒祭刀是戏曲动作，史料无载。明代死刑有监候（秋审复核）与立决之分，秋后处决是常态。
✗ 皇帝动辄「推出午门斩首」 3
✓ 午门是颁诏与廷杖之地，不是刑场；明代死刑须三法司会审、皇帝勾决。廷杖在午门执行——但那多数打不死（16/134 的死亡率见大礼议）。
✗ 「明朝的官员见官就跪」 3
✓ 百姓见官跪，官员之间不作跪礼（除大朝与特旨）；下级见上级作揖。清代跪礼才泛滥。
✗ 银锭随处掏钱 3
✓ 明初禁银，白银大规模流通是正统后（金花银）与隆庆开关后的事；洪武—宣德年间市面主要用宝钞与铜钱。写永乐朝的小说别让人掏银子买包子。
✗ 宝钞是废纸 3
✓ 宝钞确在正统后大幅贬值，但成化前仍在流通且有法定地位——「一贯钞」的购买力随年代剧烈变化，按年代写。
✗ 一两银子＝现在几千块 3
✓ 米价基准：万历年间 1 两≈2 石米（约 150–190 公斤）；折算人民 币 600–900 元区间——但明初与明末差数倍，逐朝估算。
✗ 「奉旨」都能先斩后奏 3
✓ 尚方剑是明代中后期才有的制度性授予（万历朝鲜之役、明末督师常见）；洪武—宣德朝没有「先斩后奏」的尚方剑叙事。
✗ 内阁首辅＝宰相 3
✓ 制度上无宰相：首辅无属官、不辖六部。张居正式的权力是「票拟+考成+皇帝信任」的临时组合，不是职位给的。台词里被政敌骂「僭相」反而是史实感强的写法。
✗ 「杀了个把朝廷命官没问题」的边将 3
✓ 杀官必须奏报；私杀品官是大案。边镇的现实是杀良冒功——但那是犯罪后被查处的素材，不是日常特权。
✗ 东厂番子满街抓人如黑衣人 3
✓ 东厂番役千余人的编制，行动需驾帖（凭证）；「缇骑四出」多指锦衣卫。厂卫的可怕在制度性恐怖（诏狱、告密网），不在街头火并。
✗ 诏狱想进就进 3
✓ 诏狱收人应有驾帖与旨意（刘瑾、魏忠贤时期确实经常被滥用绕过）——写正常年代要写程序，写权珰年代写程序被撕破，两处都有戏。
✗ 大臣上朝自带「笏板」排排站 3
✓ 明代用笏（牙笏）但朝会仪节与影视剧差异大：常朝御门听政在奉天门（皇极门）露天举行，百官按衙门序列东西班站立。
✗ 皇帝临朝珠帘垂面 3
✓ 冕旒（珠帘）只在衮冕大礼时用，常朝戴乌纱折上巾（翼善冠）着盘领袍——「垂旒听政」是想象图。
✗ 龙袍明黄色 3
✓ 明代皇帝常服柘黄（偏赭黄）、玄色衮服；「明黄」专属是清代定制。万历定陵出土的袍料可查。
✗ 后宫嫔妃自称「本宫」 3
✓ 「本宫」是戏曲口吻；明代后妃自称「妾」「妾身」，口语不会自称宫号。
✗ 「打入冷宫」有专门建筑 3
✓ 明代无固定「冷宫」宫殿：失势妃嫔多幽居别宫、北三所或浣衣局，位置随朝代不同。
✗ 选秀在全国公开海选 3
✓ 采选有地域与出身限制（多直隶、山东、河南等处良家女），且经多层筛选，「全天下选美」是小说化。
✗ 公主随便出宫谈恋爱 3
✓ 明代公主下嫁后驸马「尚主」礼极严，驸马见公主需行臣礼；有明一代公主与驸马会面制度化（公主府相见如君臣）。写宫廷言情请按「礼法即冲突」来设计。
✗ 「斩立决」当场写牌子 3
✓ 明代死刑复核极严：立决亦须皇帝勾决；「斩立决/绞立决」术语通行于清代文书。
✗ 锦衣卫指挥使见官高人一等 3
✓ 锦衣卫堂官品级不低但外廷官多轻视之（「缇帅」是带贬的称呼）；厂卫与文官的关系是对立多于敬重。
✗ 「八股取士＝只会写文章不会治国」 3
✓ 八股是格式不是内容：进士科场文与实务能力脱节确是批评焦点，但张居正、徐光启都是科举出身——人物塑造别贴单一标签。
✗ 火铳是稀罕物 3
✓ 明军神机营（永乐建）是世界最早成建制火器部队之一；明中期鸟铳、佛郎机已普及边军。冷兵器单挑的战争戏请留给演义。
✗ 长城是秦长城 3
✓ 今天看到的砖石长城主要是明代修建（戚继光蓟镇空心敌台是代表）；「孟姜女哭秦长城」与明代边墙要分清。
✗ 「郑和宝船万吨巨舰」 3
✓ 宝船尺度学界争议极大（大型说 vs 中型说），排水量估算从数千吨到上万吨都有——写实向作品建议模糊处理。
✗ 明代人人都裹小脚 3
✓ 缠足在明代主要流行于上层与部分地区，且形态是「纤瘦」而非清代「折骨」式；劳动妇女、辽东、西南多不缠。写市井女性请按阶层与地域区分。
✗ 靖难之役
✓ 方孝孺「诛十族」说首见于晚明祝枝山《野记》等私史，正史无载，学界存疑（等级④）
✗ 郑和首次下西洋（1405–1433 七下西洋）
✓ 「下西洋为寻找建文帝」为动机之一说（《明史》原文有此说），学界仅作辅因；「郑和船队发现美洲」属无据推测（等级④）
✗ 土木堡之变
✓ 「五十万大军」为号称，学界估计二十余万；「樊忠锤杀王振」出自晚出私史，正史载其死于乱军（等级②④并列）
✗ 壬寅宫变
✓ 宫变细节多出自私家记载与档案节引，动机至今无定论，页面须标注「史料有限」
✗ 嘉靖大倭乱与戚继光平倭
✓ 「倭寇即日本人」不确：主力为中国海商与流民，真倭比例学界多有辨析
✗ 萨尔浒之战
✓ 「四十七万大军」为号称；学界通行估计明军及朝鲜援军合计约十万上下
✗ 宁远之战
✓ 「努尔哈赤被袁崇焕大炮击伤致死」通行于通俗叙事，但《明史》仅载其年病死，伤死关联无确证（等级③④辨析）
✗ 己巳之变与袁崇焕之死
✓ 「袁崇焕通敌卖国」为当时定罪口径与后世讹传；「皇太极反间计全盘属实」亦需谨慎——《清实录》叙事与明方审案多有出入，学界至今讨论
✗ 甲申之变（李自成破京，明亡）
✓ 「崇祯血诏」文字诸本不一，需并列辨析；「太监开城导致北京陷落」中曹化淳时已退休在乡，开城说有辨析（等级②③）
✗ 成化犁庭（征建州）
✓ 「成化犁庭=种族灭绝式行动」为网络夸大表述；规模与性质以《宪宗实录》为准（等级④辨析）
✗ 应州之役
✓ 「应州大捷斩首十六级」的正史数字与战斗规模明显不称，学界多认为实录有意贬抑武宗朝武功——页面并列诸说
✗ 王恭厂大爆炸
✓ 「核爆/陨石/反物质」等网络解释均无据；脱衣现象记载出自笔记层层转抄，可信度存疑（等级④）
