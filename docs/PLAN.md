## 1. 项目定位

**一句话定位**：一个把明朝 276 年「权力如何运转、如何演变」讲清楚的中文知识网站，用动态图表和历史地图替代静态长文，让不同深度的读者各取所需。

**时间范围**：1368（洪武元年）— 1644（崇祯十七年）为主线，附南明简编（1644–1662）与明郑余绪（至 1683）作为收束章节。

**空间范围**：两京十三布政司为核心舞台，兼及奴儿干都司、乌思藏、哈密等羁縻/都司辖区，以及下西洋航线、东亚海域等对外空间。

**不做的事（边界）**：
- 不做论坛/UGC，内容全部由项目组撰写并标注出处
- 不做野史猎奇汇编：轶闻必须标注史料等级（详见 §7 写作体例）
- 二期再做：经济与社会、科技文化、对外关系专章（先以「大事」「创作者专区」覆盖其高频需求）

## 2. 受众与需求矩阵

| 需求 | 学生 | 爱好者 | 创作者 |
|---|---|---|---|
| 时间轴/大事速查 | ★★★ | ★★ | ★★★（找冲突素材） |
| 权力结构图解 | ★★★ | ★★★ | ★★★（写官场戏的依据） |
| 皇帝/人物卡片 | ★★★ | ★★★ | ★★★ |
| 交互地图（疆域/战役/航线） | ★★ | ★★★ | ★★★（地理实感） |
| 人物关系网络 | ★ | ★★★ | ★★★（人物弧线设计） |
| 轶闻考据 | ★ | ★★★ | ★★ |
| 称谓/官品/科举/物价速查 | — | ★ | ★★★（刚需） |
| 史料出处与延伸阅读 | ★★ | ★★★ | ★★★（考据型读者） |

由矩阵得出的四条产品原则：
1. **空间优先**：交互地图是全站第一入口与总览容器——**首页即地图、导航地图居首**；内容尽量「落到地图上」，地图交互按 MapCore 规范统一打磨（见 content/06）。
2. **每个内容页都是三层阅读**：一句话结论（TL;DR）→ 核心叙述 → 展开考据+出处。学生读第一二层，爱好者读第三层，创作者跳转素材库。
3. **图表优先**：能用图说清的（结构、流程、消长、地理）绝不只用文字；文字负责因果与细节。
4. **移动端优先**：学生主要用手机访问，图表必须有移动端形态（点击替代悬停、可横屏全屏）。

## 5. 技术方案

**推荐栈（默认按此执行，可整体替换）**：

| 层 | 选型 | 理由 |
|---|---|---|
| 站点框架 | **Astro 5**（静态生成 + Islands） | 内容站天然形态：数百个内容页零 JS 输出，图表按需水合 |
| 交互组件 | 原生 TS + Web Components（Astro islands）；复杂图可用 Vue 3 | 单文件组件、无框架包袱，长期可维护 |
| 图表库 | **ECharts 5**（timeline / graph / tree / custom series） | 中文文档完善、甘特与关系网络都能做、移动端可用 |
| 地图 | **Leaflet 1.9** + GeoJSON（复杂底图再考虑 MapLibre GL） | 轻量、瓦片与矢量皆可、历史地图叠加容易 |
| 地图数据 | **已入库**：明代卫所 375 点、驿站 1000 点、驿路 1042 段（CHGIS 分发，见 src/geojson/ATTRIBUTION.md）；**待处理**：明代政区边界（Hartwell GIS 79MB，V6 无明代切片）；必要处自绘简化轮廓 | 数据可用性已实测确认；注意 CHGIS 系列许可为**学术使用、禁商业/转售/再分发**（本站非商业教育定位+逐图署名合规，商业化须自绘替换）；谭其骧《中国历史地图集》有版权，**禁止扫描使用** |
| 内容层 | Astro Content Collections：`.md` 长文 + `.json` 结构化数据 | 数据与叙事分离，图表直接吃 JSON |
| 部署 | Vercel 或 GitHub Pages（静态） | 零成本、CI 自动构建 |

**数据层设计**（图表与页面的单一事实来源）：

```

  emperors/      emperors.json      # 16帝 + 南明（结构化）
  reigns/        reigns.json        # 在位区间（甘特图数据）
  events/        events/*.json      # 大事（时间轴数据，含分类/关联）
  figures/       figures/*.json     # 人物（含生卒/类别/关系边）
  secretaries/   first-secretaries.json  # 内阁首辅序列（《明史·宰辅年表》整理）
```

**设计基调**：宣纸底色 + 传统色（参考《中国传统色》取明代织物色系）、思源宋体标题/思源黑体正文、暗色模式、章节页配篆刻风格印章元素。视觉浓度克制，信息优先。

## 7. 写作体例（全站约束，先立规矩）

1. **史料等级标注**：每处史实标注来源等级——
   - ① 正史/官修（《明史》《明实录》《大明会典》）
   - ② 当时人著述（《国榷》《万历野获编》《明史纪事本末》等）
   - ③ 现代研究（孟森、黄仁宇、樊树志、顾诚等）
   - ④ 传闻/野史/文艺作品（明确标「传说」「演义」，不得混入正文叙述）
2. **争议并列**：学界有分歧处（如建文下落、明初人口、壬寅宫变细节）并列诸说并注明，不取独断。
3. **术语弹窗**：全站术语（票拟、批红、廷杖、卫所、京察……）首次出现挂 glossary 弹窗，学生友好。
4. **古今对照**：所有历史地名首次出现附今地（如「西安＝今陕西西安」）。
5. **公历换算**：全部年份括注公元纪年；日期精确到「农历月日」时注明历法。
6. **误区辨析框**：常见影视误区（如「锦衣卫人人飞鱼服」「明代皇帝称官家」）以醒目组件呈现，服务创作者。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 史实错误（最大风险） | 双人/双模型交叉校对；关键数据回溯到一手史料；正文挂出处 |
| 地图版权 | CHGIS 系列许可为「学术使用、禁商业/转售/再分发」（比预想严格）：本站以非商业教育定位+逐图署名+来源 DOI 使用；**若商业化或需完全开放再分发，边界层替换为自绘**；谭图仅作研究参照不发布 |
| 工程量失控 | 严格分期交付；每模块先出「骨架页+核心图」再填充 |
| 图表移动端不可用 | 每个图表规格里写明移动端交互方案，作为验收标准 |
| 内容深度不均 | 大纲先行（本次产出），每页按模板字段写作，字段不全不算完成 |
