## 一、一手史料（等级①②）

### 核心正史与官修
| 文献 | 说明 | 全站用途 |
|---|---|---|
| 《明史》（张廷玉等，332 卷） | 清修正史，本纪 24/志 75/表 13/列传 220 | 帝王、职官、后妃、列传主干；**注意**清修政治滤镜（建州叙事、南明处理）需与现代研究校核 |
| 《明实录》（太祖—熹宗十三朝 + 崇祯长编） | 逐日编年，最详尽的一手档案汇编 | 时间校对的最终依据；数字（兵力/灾异）核出处 |
| 《大明会典》（正德本/万历重修本） | 官修行政法典，制度条文总汇 | 职官、礼制、宫分待遇、科举程式的条文依据 |

### 当时人著述（等级②，用于细节与现场感）
- 谈迁《国榷》——私修编年，建州与革除之际记载可补《明史》讳处
- 谷应泰《明史纪事本末》——80 卷本末体，事件叙事骨架好用（成书早于《明史》，个别细节需校）
- 沈德符《万历野获编》——掌故百科，后宫/风俗/「对食」等词条出处
- 王世贞《嘉靖以来首辅传》《弇山堂别集》——首辅序列与阁部掌故
- 孙承泽《春明梦余录》——北京官署与制度运作细节
- 焦竑《国朝献征录》——明人传记资料汇编（人物生卒校核）
- 《万历会计录》——财政数据（V15 图表主源）
- （对外）朝鲜《李朝实录》——壬辰战争对方视角、殉葬记录、建州早期情报

### 数字检索入口（免费）
- **中国哲学书电子化计划 ctext.org**（含《明史》全文检索）
- **台湾「汉籍电子文献资料库」**（《明实录》在线）
- 维基文库（校对用，不作最终依据）
- ⚠️ 各商业古籍库（爱如生等）内容不得直接转载，仅可检索引用

## 二、现代研究著作（等级③，叙事观点的基准）

### 通史与讲义
- 孟森《明史讲义》——断代讲义范本，史实骨架首选
- 樊树志《晚明史（1573–1644）》与《明史十讲》——晚明叙事基准
- 卜正民《挣扎的帝国：元与明》（哈佛中国史卷）——全球史视角，学生友好

### 专题研究
- 黄仁宇《万历十五年》《十六世纪明代中国之财政与税收》——大历史观与技术财政（观点鲜明，采用时注明「黄仁宇观点」）
- 顾诚《南明史》——南明叙事权威，兼及明末党争、农民军的批判性考订
- 钱海岳《南明史》（纪传体，与顾诚互补）
- 吴晗《朱元璋传》——开国叙事经典（注意其时代局限，标注）
- 何炳棣《明初以降人口及其相关问题》——人口数据基准
- 陈宝良《明代社会生活史》——创作者专区衣食住行的主源
- 郭培贵《明史选举志考论》——科举制度细节（V17 主源）
- 王天有《明代国家机构研究》——职官结构（V1 主源）
- 赵现海《明代九边长城军镇史》——九边军镇（V8 主源）

### 通俗读物（等级④，仅作「当代接受」素材，不作出处）
- 当年明月《明朝那些事儿》、张宏杰《大明王朝的七张面孔》——用于「流行叙事 vs 史实」辨析框

## 四、使用规范（写作时的硬规则）

1. **每页页脚「参考文献」组件**：分级列出本页引用（①②③④ 着色）
2. 引用格式统一：`作者《书名·卷次/篇名》+ 现代出版物信息（出版社，年份）`
3. 《明史》与《明实录》冲突时：以实录为准但明示分歧；《明史》明显带清初政治处理处（建州、南明）以顾诚/樊树志校正
4. 网络说法（自媒体、小说、影视剧）一律不入正文出处；集中放「误区辨析」
5. 每月复核一次链接有效性（ctext/汉籍库 URL 变动）

## 五、Phase 0 研究任务所需的阅读顺序建议

1. 先读孟森《明史讲义》+ 樊树志《明史十讲》（骨架与分期观）
2. 对照《明史》本纪十六篇（帝王时间线）
3. 职官志 + 《大明会典》目录（V1/offices.json）
4. 《宰辅年表》（V4）+《后妃传》（M3）
5. 按模块需要再入专题研究（本页第二节对照表）
