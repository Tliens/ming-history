## A. 制度解剖（静态结构，配 V1 分时期组织结构图）

### A1 皇帝
- 皇权理论基础：天命、祖制（「皇明祖训」的约束力与虚化）
- 皇帝的日常制度：朝会（大朝/常朝/御门听政）、经筵、批红义务
- 明代皇权的特殊性：废相后皇帝直接领导六部，「皇帝不作为」时代机器如何空转（万历怠政案例）

### A2 中枢决策链（配 V2 流程图「一份奏章的旅程」）
```
题本/奏本 → 通政司 → （内阁票拟 → 司礼监批红）→ 六科抄发封驳 → 六部/都察院执行 → 塘报/邸报
                    ↘ 特殊通道：密奏、东厂密报、驿传直奏
```
- 关键机制逐个讲清：票拟、批红（朱批/代批）、封驳、留中、廷议、会推

### A3 内阁
- 起源：洪武十三年（1380）废丞相（胡惟庸案）→ 十五年设殿阁大学士（顾问）→ 永乐特简翰林官入直文渊阁（内阁成形）→ 宣德—正统间票拟制度化
- 四殿二阁：中极殿（旧华盖）、建极殿（旧谨身）、文华殿、武英殿、文渊阁、东阁
- 首辅制：非正式但实存的「首揆」，次序之争（张居正与张四维/申时行过渡案例）
- 内阁的权力边界：有票拟无执行、无属官、不统六部——为何「相权」始终残缺
- 「非进士不入翰林，非翰林不入内阁」的晋升闭环

### A4 宦官系统
- 二十四衙门（十二监四司八局）总览；司礼监为何凌驾诸监（批红 + 提督东厂）
- 内书堂（宣德设）：宦官读书的制度化，是宦官干政的技术前提
- 掌印太监 vs 秉笔太监（「内相」与「二皇帝」格局）
- 厂卫：锦衣卫（洪武十五年，1382，南北镇抚司、诏狱）、东厂（永乐十八年，1420）、西厂（成化十三年设/十八年罢；正德复设/五年罢）、内行厂（正德，刘瑾）
- 厂卫与京师的日常监控生态
- 平衡视角：明代宦官权出自皇权（与唐末宦官废立皇帝对比），「贤珰」谱系（郑和、怀恩、陈矩、王安、王承恩）

### A5 六部与科道
- 六部尚书（吏户礼兵刑工）+ 都察院左右都御史 = 七卿；加大理寺卿、通政使 = 九卿
- 吏部之权重（「部权」与阁权之争：廷推、京察、大计）
- 六科给事中（封驳、注销）与十三道监察御史 = 「科道」言官系统
- 言官的攻击性与政治生态（「京察」成了党争武器）

### A6 军事系统
- 五军都督府（中左右前后）— 都指挥使司 — 卫（5600人）— 千户所 — 百户所
- 兵将分离：调兵权（兵部）vs 统兵权（都督府）vs 练兵权
- 军户世袭与卫所屯田；卫所制崩坏（军逃、屯田侵吞）→ 募兵制兴起（戚家军、川兵、白杆兵）
- 京营：三大营（五军、三千、神机）→ 十团营 → 戚继光蓟镇练兵
- 矿监/税监不是军事但属于太监出侵地方权力的分支 → 放 A4 或演变篇

### A7 地方治理
- 洪武九年行中书省 → 承宣布政使司（民政）+ 按察使司（监察司法）+ 都指挥使司（军事）三权分立
- 两京十三布政司（俗称十五省）：北直隶、南直隶 + 山东、山西、河南、陕西、四川、湖广、浙江、江西、福建、广东、广西、云南、贵州（永乐十一年设）
- 三司互相牵制导致协调难 → 巡抚（宣德起常态化）→ 总督（跨省军务）→ 明末督师
- 边疆建置：奴儿干都司（1409）、乌思藏都司、哈密卫、交趾布政司（1407–1427）、土司制度与改土归流

### A8 司法与诏狱
- 三法司（刑部、大理寺、都察院）常规司法
- 非常规：诏狱（锦衣卫北镇抚司）、东厂、「会审大案」；廷杖制度（折辱士大夫的政治符号）
- 廷杖实录案例：左顺门哭谏（嘉靖，134 人下狱、16 人杖死）

### A9 科举与铨选（权力再生产的管道，配 V17）
- 官学—科举闭环：社学/县州府学 → 童试（秀才）→ 乡试（举人/解元）→ 会试（贡士/会元）→ 殿试（进士/状元榜眼探花）
- 三年一科、南北卷（洪熙定南北中卷比例，区域配额政治）
- 庶吉士—翰林院—内阁的「储相」通道；举人/监生的下沉仕途（海瑞即举人出身）
- 铨选：吏部四司、廷推、掣签（崇祯末的无奈）

### A10 宗室（藩王）
- 洪武分封塞王（九大塞王守边）→ 建文削藩 → 靖难 → 永乐后「藩禁」（二王不相见、不得出城、不得入朝）
- 宗禄问题：宗室人口膨胀与地方财政拖累（《万历会计录》数据，配 V15 小图）
- 特例：靖江王、沐氏世镇云南（实际是勋镇不是藩王体系，需辨析）

### A11 外戚与勋贵
- 明代为何基本无外戚之祸：后妃多选自民间、封爵不任事、地理分散（详见 M3）

## B. 权力演变（动态叙事，配 V3 消长时间轴 + V4 首辅序列）

九个阶段，每阶段一页，固定结构：**格局特征 → 关键事件 → 权力得失 → 承上启下**。

| 阶段 | 时期 | 格局关键词 | 核心事件 |
|---|---|---|---|
| B1 皇权奠基 | 洪武（1368–1398） | 废相、酷烈整肃 | 胡惟庸案（1380，废丞相）、蓝玉案（1393）、空印案、郭桓案、铁牌「内臣不得干预政事」 |
| B2 削藩与逆转 | 建文（1398–1402） | 文官改制 + 激进削藩 | 建文新政、靖难之役、方孝孺案 |
| B3 永乐重构 | 永乐（1402–1424） | 内阁+东厂双轨、藩禁完成、迁都 | 设内阁、设东厂（1420）、削藩完成、迁都北京（1421）、下西洋、奴儿干都司 |
| B4 仁宣过渡 | 洪熙—宣德（1424–1435） | 三杨辅政、内阁制度化 | 票拟制度化、内书堂教宦、巡抚常态化、放弃交趾、宣宗织造/蟋蟀（爱好者的梗，标注史料等级④） |
| B5 危机与挽回 | 正统—天顺（1435–1464） | 宦官第一次专权、土木堡、夺门 | 王振专权、土木堡之变（1449）、北京保卫战（于谦、兵部抬头）、夺门之变（1457）、曹石之乱、门达/逯杲 |
| B6 膨胀与整饬 | 成化—弘治（1464–1505） | 西厂、传奉官、弘治回调 | 汪直与西厂、成化犁庭、荆襄流民（郧阳抚治）、万贵妃宫闱、纸糊三阁老/泥塑六尚书（②级时评）、传奉官、弘治中兴（刘大夏、马文升） |
| B7 权相与青词 | 正德—嘉靖—隆庆（1505–1572） | 皇权怠政 → 阁权、宦权填补 | 刘瑾八虎、豹房、大礼议（1521–1524，杨廷和去职）、嘉靖修玄不上朝、严嵩专权二十年、庚戌之变（1550）、徐阶倒严、隆庆开关（1567）、俺答封贡（1571） |
| B8 阁权顶峰与崩解 | 万历（1572–1620） | 张居正时代 → 怠政空转 → 党争 | 冯保+李太后+张居正铁三角、考成法、一条鞭法（万历九年全国推行）、张居正身后清算、国本之争（1586–1601）、妖书案、怠政二十余年、矿税太监、东林与齐楚浙党、三大征（1592–1600）、萨尔浒（1619） |
| B9 阉焰与倾覆 | 天启—崇祯（1620–1644） | 阉党专权 → 崇祯翻覆 | 移宫案、魏忠贤与阉党（东林六君子狱）、崇祯清算阉党、十七年五十阁相、己巳之变（1629）与袁崇焕之死、民变与后金两线作战、甲申之变（1644） |

**贯穿性专题页**（跨阶段机制，从 B 中抽出）：
- 票拟与批红的博弈史：阁权与宦权的此消彼长（配 V3 叠加对照）
- 言官政治：从矫正器到党争武器
- 「不上朝」≠「不管事」：嘉靖/万历的遥控术（批红、密奏、人事控制）
- 明代宦官专权为何不能篡位（与汉唐对比，权力来源分析——学生最常问）
