> 本文档是网站结构的最终依据；PLAN §4 为其摘要。结构设计的底层逻辑先行，再落路由树、页面模板、导航与动线。

## 一、组织逻辑：知识形态决定页面形态

明代知识在本站分四种形态，每种配一种呈现方式——这是全部结构决策的出发点：

| 知识形态 | 例子 | 呈现方式 | 对应模块 | 结构地位 |
|---|---|---|---|---|
| **空间型（看地理）** | 疆域、九边、战役、航线 | 交互地图 | /maps | **第一入口：首页形态与全站总览容器** |
| 叙事型（讲因果） | 权力演变九阶段、甲申倒计时 | 长卷/分步页 + 消长时间轴 | /power/evolution、/topics | 叙事主线 |
| 索引型（查条目） | 皇帝、人物、后妃、术语 | 卡片 + 筛选 + 弹窗 | /emperors、/figures、/harem | 检索层 |
| 规则型（查规矩） | 职官结构、位号、官品、称谓 | 结构图 + 速查表 + 工具 | /power/structure、/creators | 工具层 |

四条结构公理（一图、一轴、一线、三动线）：
1. **一张地图做入口**：空间最直观——**首页即地图**，导航第一项是地图；所有模块的内容都尽量「落到地图上」，地图是全站总览容器，不是并列板块之一。
2. **一条时间轴做坐标**：1368–1644 / 十六帝是全站统一的时间坐标，任何列表页都能按朝代切片（见「时间锚」组件）；地图与时间轴深度联动（见 06 号文档 MapCore 规范⑤）。
3. **一条权力线做主线**：权力结构与演变仍是叙事主干，其他模块都为主线提供「侧写」——事件是主线的节点，人物是主线的执行者，皇帝是主线的主人，后宫是主线的暗面。
4. **三类动线**：学生走引导路线、爱好者走交叉链接、创作者直取工具区——一套内容，三种走法。

## 四、导航系统

### 4.1 桌面顶栏
```
[印章Logo·明史=首页] 地图 权力 皇帝 后宫 大事 人物 专题 创作者   [搜索] [更多▾ 资料库/术语表/关于]
```
九项主入口（**地图居首**，首页由 Logo 承担）+ 搜索 + 折叠菜单；「更多」收纳低频静态页。

### 4.2 时间锚（全站统一组件，本站特色）
- 形态：十六朝代段的横向色条（洪武→崇祯），可点击
- 出现位置：**所有列表/索引页**（作为筛选器）与**所有详情页顶部**（作为「你在这里」定位，高亮当前朝代）
- 详情页内点击其他朝代 = 跳转到该朝代的模块视图（如从「于谦」跳到景泰朝人物列表）
- 作用：把「时间坐标系」变成全站的物理导航，学生随时知道自己身在 276 年的哪一段

### 4.3 详情页上下文区（统一「四联卡」）
每个条目详情页底部固定四类关联卡：**同期皇帝 / 相关事件 / 相关人物 / 相关图表**——保证跨模块跳转永远有出口。

### 4.4 正文内链三层
- 术语 → glossary 弹窗（不跳页）
- 人名 → 人物 hover 预览卡（点开进详情）
- 地名 → 地图锚点（跳到对应地图并定位）

### 4.5 移动端
- 顶栏收为 Logo + 搜索 + 抽屉（全量导航）
- 底部 Tab 四键：**地图(/maps)** / 时间轴(/events) / 皇帝(/emperors) / 搜索（首页由顶部 Logo 进入，地图占据最顺手的首键位）
- 图表全屏化交互（横屏提示），时间锚变为横向滑动条

### 4.6 搜索（pagefind 静态索引）
- 全量条目 + 术语 + 专题；支持「于谦」「票拟」「1582」三种查询（人名/术语/年份都命中）
- 年份命中直接展示时间轴定位（联动 V6），是搜索的特色能力

## 五、三类受众动线（验收用场景）

**学生（线性）**：首页地图 Hero（先拖一拖时间滑杆、点一点政区，建立空间感）→「第一次来」→ `/learn/beginner` 十步（先看地图认版图→概览→权力机器→九阶段→十六帝→后宫→大事→人物→考据方法→误区）→ 每步勾选进度 → 结业后自由漫游。
**爱好者（网状）**：地图中心 → 明末战局图点击萨尔浒 → 事件详情 → 参战人物杜松/刘綎 → V14 网络切片「万历武将圈」 → 同期皇帝万历 → V4 首辅对位。全程只靠交叉链接，不碰导航。
**创作者（工具直达）**：搜索引擎收藏直达 `/creators/titles` 查「太监面称」→ 误区清单比对 → 官品速查定品级 → 顺术语弹窗进 `/power/structure` 看司礼监位置 → 案例人物冯保页抄素材；写战争戏先到 `/maps` 选定战场地理（如辽东）再回正文考据。

## 六、URL 与 slug 规范

- 全小写、连字符、层级 ≤3；功能页用英文（power/events/maps/creators/learn/topics），条目用拼音
- 皇帝 slug 用最通行年号拼音：`hongwu / jianwen / yongle …`；**英宗例外**用 `yingzong`（两度年号）
- 人物：`yu-qian / zhang-juzheng`；事件：`jingnan / tumu-crisis / sa-er-hu`（音节间用连字符，代码中维护 slug 映射表防歧义）
- **slug 一经发布不改**（外链稳定性）；标题可改
- 筛选状态（时间轴轨道、人物筛选）走 URL query/hash，可分享、可回退
