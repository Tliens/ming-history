# M6 · 可视化图表与地图 · 完整规格

> 每项规格：**回答什么问题 → 图表类型 → 数据与来源 → 交互（桌面/移动）→ 优先级**。
> 优先级：P0 = 首发必备；P1 = v1.0 内；P2 = v1.x 增强。
> 技术基线：ECharts 5（图）+ Leaflet 1.9（地图），见 PLAN §5。

## 一、结构图类

### V1 权力结构组织图 · P0
- **回答**：明朝中央/地方权力机器长什么样？四个代表时期有何不同？
- **类型**：ECharts tree/graph 可缩放组织图，含「洪武（废相后）/ 永乐 / 正德 / 万历」四期切换；节点点击弹出词条卡
- **数据**：`offices.json`（自建，依据《明史·职官志》《大明会典》）+ 各期差异标注（如永乐期新增「内阁」「东厂」高亮）
- **交互**：桌面拖拽缩放+悬停高亮路径；移动端点按展开子树、双指缩放；提供「精简版」（只显示三层）
- **验收**：非历史专业用户 30 秒内说清「皇帝—内阁—六部—司礼监」的位置关系

### V2 一份奏章的旅程（决策流程图）· P0
- **回答**：票拟、批红、封驳、执行到底怎么走？
- **类型**：自定义流程图（ECharts graph + SVG 边），分步动画「播放」一份奏章从呈递到执行；分支路径（留中、驳回、下诏狱）
- **数据**：流程规则来自《明史·职官志》《春明梦余录》
- **交互**：步进/自动播放；移动端竖排布局

### V16 后宫位分层级图 · P2
- 类型：层级树 + 各级待遇侧栏（冠服/宫分，《大明会典》辑录）

## 二、时间轴与序列类

### V3 权力消长时间轴 · P0（全站招牌图）
- **回答**：276 年里皇权、阁权、宦权、言官力量怎么此消彼长？
- **类型**：自定义多层时间轴：上层为十六帝在位色带，下层以「事件点+强度曲线」示意四种力量的兴衰（曲线为**叙事示意**，明确标注非量化数据，避免伪精确——学术诚实设计）
- **数据**：制度事件清单（M1-B 九阶段）；强度赋值依据学界共识叙述，附「我们如何绘制」方法页
- **交互**：点击事件点跳转 M4 事件页；拖动时间光标联动 V1 时期切换
- **移动端**：纵向时间轴模式

### V4 首辅序列与皇帝对位 · P1
- **类型**：双列甘特（上：皇帝在位；下：历任首辅任期），首辅条点击进人物页
- **数据**：《明史·宰辅年表》整理为 `first-secretaries.json`（约 80 任）；兼任/短任标注

### V5 世系树 + 在位甘特 · P1
- **类型**：上为父子世系树（D3 dendrogram 或 ECharts tree），下为十六帝在位甘特条（靖难、夺门等政变以红线连接）
- **数据**：`emperors.json`；画像占位（版权方案见 TODO-R8）

### V6 大事交互时间轴 · P0
- **类型**：五轨时间轴（政治/军事/经济/文化/对外），可按轨、按帝筛选，事件密度热区
- **数据**：`events.json` 全量

### V17 科举晋升路径图 · P1（创作者刚需）
- **类型**：Sankey/流程图：童生→县府院试→秀才→乡试→举人→会试→贡士→殿试→进士（三甲）→ 庶吉士→翰林→入阁；旁路：举人大挑/教职/监生
- **数据**：《明史·选举志》、郭培贵研究；附各阶层录取率量级与别称（解元/会元/状元）

### MapCore 交互规范（全站地图统一内核 · 逐条验收）

> 所有地图（V7–V13、V18）共用 MapCore 组件实现；本规范即地图交互的验收标准，地位等同「六、通用工程要求」。

**① 时间滑杆——「拖动 276 年」（招牌交互）**
- 每张历史地图顶部横贯时间滑杆（1368–1644，带十六帝刻度）：拖动即切换政区切片、事件点显隐、战线位置；松手前预览低精度层、松手后载入精细层
- 战役地图（V9/V11/V13）滑杆粒度切换为战役进程（按日/按月）
- 首页 Hero 预览模式也必须有时间滑杆（轻量版）——用户第一眼就能「拖动历史」

**② 图层系统**
- 统一图层面板（开关 + 图例）：政区着色 / 都司建置 / 卫所点 / 九边·长城 / 驿路 / 战役路线 / 事件点 / 今省界对照 / 今地名 / 地形晕染
- 各地图主题预设默认图层组合；图层状态写入 URL

**③ 古今对照三件套**
- 历史层↔现代底图透明度滑杆；双卷帘（split-swipe）左右拖动对比；现代底图浅色/卫星切换

**④ 点击与悬停的分层行为**
- 政区面 → 右侧面板卡：布政司/都司介绍、治所、该地事件与人物列表（面板内可继续跳转）
- 城市/卫所点 → tooltip：古今名对照、职能、关联条目直达
- 事件点 → 浮层迷你卡（四段式摘要 +「查看详情」）
- Hover：区域高亮 + 古今名标签同步显示

**⑤ 图↔轴联动（brushing & linking）**
- V6 时间轴 / V3 消长轴上点选事件 → 地图自动飞到定位、标记脉冲 3 秒
- 反向：地图框选/点选区域 → 时间轴过滤为该区域事件（空间驱动的检索）

**⑥ 战役动画控制条**
- 播放 / 暂停 / 逐帧 / 倍速（0.5×/1×/2×）；行军路线渐次绘制；关键节点自动暂停弹出注记；支持「跳到下一节点」

**⑦ LOD 分级标注**
- 远景：布政司名与界 → 中景：+府/直隶州治所 → 近景：+县、卫所、驿铺；标签碰撞退避（先大后小、先重要后次要）

**⑧ 移动端交互（重点打磨）**
- 内嵌地图默认锁定缩放（不劫持页面滚动），提供醒目「进入全屏地图」按钮
- 全屏内：双指缩放、单指拖动、双击放大；时间滑杆变为底部大滑块（拇指可达）；右侧面板变底部抽屉
- 系统返回手势优先退出全屏（不误触离开页面）；横屏提示用于战役图

**⑨ 性能预算（硬指标）**
- 地图首包 JS ≤200KB gzip（Leaflet 核心 + MapCore，不含数据）；政区数据 ≤150KB（TopoJSON 按 zoom 三档分级加载）
- 动画 60fps（缩放/拖动期间暂停动画帧渲染）；卫所等千点级图层用 canvas 渲染
- 中端安卓真机：首屏地图可交互 ≤3s

**⑩ 状态可分享与降级**
- center / zoom / 图层 / 年份全部编码进 URL hash，打开即还原——「把我看的这条路线发给别人」
- 无 JS / SSR 环境降级为静态 SVG/PNG；每张地图配「文字版地理叙事」（SEO 与无障碍共用）
