## C. 每帝详情页模板（16 页共用）

1. **信息卡**：庙号/姓名/生卒/在位/年号/享年/陵寝/世系/画像（注意版权，用公有领域拓片或自绘，见 TODO-R8）
2. **一句话定位 + 三段式生平**（TL;DR / 详叙 / 考据）
3. **当朝权力格局**：该朝的内阁/司礼监/六部构成，链接 M1（配当期 V1 切片）
4. **大事时间线**：在位期间事件（链接 M4）
5. **关键人物**：后妃、首辅、大珰、名将（链接 M3/M5）
6. **史评摘录**：正史赞语 + 孟森/黄仁宇/樊树志等现代评断（引文格式统一）
7. **轶闻与辨析**：标注史料等级④的传说单独成框，防止污染正文
8. **创作者视角**：该朝写小说的「高光冲突点」与可用素材（如景泰朝：兄弟囚禁南宫七年）
