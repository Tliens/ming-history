## 三、间距/圆角/阴影/层级

- 间距：4px 基网格，`--sp-1..8 = 4/8/12/16/24/32/48/64`
- 圆角：`--r-s 4px`、`--r-m 8px`、`--r-l 16px`；卡片用 `--r-m`
- 阴影：低海拔 `--shadow-1: 0 1px 3px rgba(43,38,32,.12)`；浮层 `--shadow-2: 0 4px 16px rgba(43,38,32,.18)`
- z-index：`--z-map 0`、`--z-panel 500`、`--z-nav 900`、`--z-modal 1000`、`--z-toast 1100`

## 四、视觉元素规范

- **印章 Logo**：24–40px 朱砂方印（`--c-vermilion` 底 + 纸色篆意「明」字），CSS 实现，禁用位图
- **分隔纹样**：卷首/章末用细横线 + 中心菱形点（CSS `::before`），禁用花哨边框
- **史料等级标**：行内小方标（10px），色取 `--c-source-N`，悬停出释义
- **考据框/误区框**：左侧 3px 竖线（`--c-disputed`）+ 浅底（`--c-disputed` 8% 透明度）+ 图标（🔍/⚠ 线性图标）
- **时间锚（朝代条）**：高 28px，各朝段按十六朝色带着色，当前朝加 2px 底线 + 年号名 12px

## 五、暗色模式

`prefers-color-scheme: dark` 或手动切换；底 `--c-mo`、文字 `--c-paper-d`；地图底图换深色瓦片；图表色明度 +10%。token 全部以语义变量引用，禁止组件内写死色值。

## 六、可访问性

- 正文对比度 ≥ 7:1（`#2B2620` on `#F7F3E8` ≈ 12:1）
- 强调色同时用于 ≥2 通道（色 + 图标/下划线），照顾色觉障碍
- 触控热区 ≥ 44px（时间滑杆手柄 28px 视觉 + 44px 命中区）
