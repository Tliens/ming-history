# D4 · 图表视觉规范（ECharts 主题）

> 主题文件：`src/styles/echarts-theme.json`（`echarts.registerTheme('ming-history', theme)` 全站统一注册）。

## 使用规则

1. **配色**：一律取主题十色（D1 token `--chart-1..10`），禁止图表内自定义色；同一数据系列跨图颜色语义一致（如「皇帝」恒柘黄、「宦官势力」恒朱砂）
2. **十六朝色带**：任何横轴为年份的图表，背景叠加十六朝分段色（D1），保证与 V3/V6/MapCore 时间滑杆视觉同构
3. **图例/脚注**：每图底部固定脚注行——数据出处（C3 标）+「示意性声明」（凡叙事示意曲线，必须标「非量化数据」）
4. **字号**：轴标签 12px，图例 12px，标题 18px；移动端标题降 16px、图例折行
5. **空态**：无数据时显示居中「数据暂缺」+ 灰色印章图标，不画空坐标系
6. **加载**：ECharts 岛屿懒加载；容器骨架为史料底色块 + 中央「制图中…」
7. **暗色模式**：随 `prefers-color-scheme` 切换主题 JSON 的镜像版（Phase 2 E7 实现）
8. **导出**：图上「下载 PNG」按钮导出时自动带上出处脚注与站名水印（右下 12px）
