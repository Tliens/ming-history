# D2 · 页面骨架线框（四类页面 × 双端）

> 低保真结构稿（区划与层级，非视觉稿）。视觉一律引用 D1 token；组件一律引用 D3 编号（C1–C12）。
> 路由与页面类型对应关系见 content/08 §三。

## 1. T1 首页 `/`（地图即 Hero）

### 桌面（≥1024px）
```
┌────────────────────────────────────────────────────────────┐
│ [印章明]  地图 权力 皇帝 后宫 大事 人物 专题 创作者  [🔍] [更多▾] │ ← 顶栏 h64 固定
├────────────────────────────────────────────────────────────┤
│                                                            │
│              全幅交互地图 Hero（70vh，V7 预览模式）              │ ← 拖动时间滑杆=首屏第一动作
│   「明朝 1368–1644」标题叠加左上 · [进入完整地图] 右下            │
│   底部通栏时间滑杆（MapCore ①）                                 │
├────────────────────────────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                     │
│ │第一次来？  │ │按主题深挖 │ │创作素材   │  ← 三受众入口卡 h160   │
│ │十步学习线 │ │六大模块  │ │直取工具区 │                      │
│ └──────────┘ └──────────┘ └──────────┘                     │
├────────────────────────────────────────────────────────────┤
│  十六帝快览条（横向滚动卡片：画像+年号+一句话，↔ 滑动）             │ ← 复用 emperors 数据
├────────────────────────────────────────────────────────────┤
│  大事时间轴精选（内嵌 V6 精简版，六件大事可点）                    │
├────────────────────────────────────────────────────────────┤
│  专题推荐三卡（/topics 招牌长文）  │ 站点规模数据（词条/人物/地图）   │
├────────────────────────────────────────────────────────────┤
│  页脚：四级史料说明 · 资料库 · 关于 · 反馈                        │
└────────────────────────────────────────────────────────────┘
```

### 移动（<720px）
- 顶栏收为 `印章 + 🔍 + ☰`；Hero 地图 60vh、**时间滑杆底部大滑块**（拇指区 44px）
- 三受众入口改为纵向三行卡；十六帝条变 2 行网格滚动；底部 Tab：地图/时间轴/皇帝/搜索
- 首屏只保留 Hero + 入口卡（其余懒加载）

## 5. 通用规格

- 内容最大宽度 1200px（长文正文 720px 限宽，中文阅读最优）
- 断点：720 / 1024 / 1200（三档；图表按 08 §四 规则自适应）
- 所有页面必备：面包屑（T3/T4/T5/T7）、页脚史料说明、时间锚（列表与详情页）
- 空态/加载态：骨架屏（史料底色块），禁止白屏
